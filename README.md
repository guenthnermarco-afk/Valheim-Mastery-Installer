# Valheim Mastery

Build your character through 21 skills, discover new ways to fight and explore, and earn equipment that shows what you have mastered. Mastery adds Prayer, Slayer, magic, skillcapes and a voluntary community leaderboard to Valheim, with English and German support.

## Install or update

[Download the Windows installer](https://github.com/guenthnermarco-afk/Valheim-Mastery-Installer/releases/latest/download/Valheim-Mastery-Installer.zip)

Close Valheim, extract the ZIP and run Installieren.exe. Pick your Valheim folder and follow the installer. Existing settings and progress are retained. Update the server and every player together.

Current release: **0.17.5 / Installer V75**. [What's new](https://github.com/guenthnermarco-afk/Valheim-Mastery-Installer/releases/tag/v0.17.5).

## Deutsch

Entwickle deinen Charakter über 21 Fertigkeiten weiter, probiere neue Kampfstile und Magie aus und verdiene Ausrüstung, die deine Meisterschaft zeigt. Dazu gehören Gebete, Slayer-Aufträge, Skillcapes und eine freiwillige Community-Rangliste.

Zum Installieren oder Aktualisieren Valheim schließen, die ZIP entpacken und Installieren.exe starten. Bestehende Einstellungen und Fortschritte bleiben erhalten. Server und alle Mitspieler gemeinsam aktualisieren.

[Fehler oder Balancing melden / report an issue](https://github.com/guenthnermarco-afk/Valheim-Mastery-Installer/issues/new/choose)

Optional diagnostics update Downloads/mastery_diag.zip locally every 15 minutes; there is no automatic upload. Die optionale Diagnose bleibt lokal und wird nicht automatisch hochgeladen.
