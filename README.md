# Valheim Mastery – Freundespaket

Hier gibt es das vollständige Windows-Installationspaket für unsere gemeinsame Valheim-Version. Es enthält Valheim Mastery, BepInEx, die benötigten Abhängigkeiten und die abgestimmten Komfortmods. Quellcode und Spielstände werden hier nicht veröffentlicht.

**[Aktuelles Freundespaket herunterladen](https://github.com/guenthnermarco-afk/Valheim-Mastery-Freundespaket/releases/latest/download/Valheim-Mastery-Freundespaket.zip)**

Valheim auf beiden Rechnern vollständig beenden, die ZIP entpacken und `Installieren.exe` starten. Der Installer sichert ersetzte Dateien, erhält bestehende Spielstände und Konfigurationen und kann für Updates erneut ausgeführt werden. Alle Mitspieler sollten dieselbe Paketversion verwenden. Die Versionsnummer und SHA-256-Prüfsumme stehen im jeweiligen Release.

Das Paket ist für Windows 10/11 x64 und die im Release genannte Steam-Valheim-Version gebaut. Es ist ein inoffizielles Fanprojekt, inspiriert von RuneScape/OSRS, ohne Verbindung zu Iron Gate oder Jagex. Drittanbieter-Mods bleiben Eigentum ihrer jeweiligen Autoren; ihre Hinweise und Lizenzen liegen im Paket.

Ältere Versionen bleiben unter [Releases](https://github.com/guenthnermarco-afk/Valheim-Mastery-Freundespaket/releases) verfügbar. Bei einem Update dieselbe Installationsanleitung befolgen. Der Link oben zeigt immer auf den neuesten Release.
